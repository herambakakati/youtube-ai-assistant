# YouTube AI Assistant

An AI-powered assistant that helps you understand YouTube videos through natural conversation. Add a YouTube video, process its transcript, and ask questions to get answers grounded in the video's content.

## What it does

- 🎥 Accepts YouTube video links
- 📝 Retrieves and processes video transcripts
- 🔎 Splits transcript content into searchable chunks
- 🧠 Uses embeddings for semantic search
- 📚 Stores transcript chunks in Chroma
- 💬 Answers questions using Retrieval-Augmented Generation (RAG)
- 📄 Generates a downloadable conversation PDF
- 📊 Provides a project presentation with workflow and screenshots
- 🖥️ Includes a Streamlit-based premium user interface

## Technology Stack

- Python
- Streamlit
- LangChain
- OpenAI
- Chroma
- YouTube Transcript API
- ReportLab
- python-pptx
